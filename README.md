# VICE FRAME — GTA-Style Cover Art Maker

Turn your own photo into a multi-panel Vice City poster, right in your browser —
no upload, no account, no network. Made for the
[Make GTA 6 Cover Art](https://make.fun/c/gta6-cover-art-01) bounty on make.fun.

## What it does

- **Load your photos** from your machine (or try the two built-in samples) and
  drop them into panels.
- **Four poster layouts** — hero + duo, 2×2 grid, tall + stacked strip, and a
  split duo — with a different photo per panel.
- **Crop and position each photo** — click a panel, drag the photo inside it,
  or use the zoom / shift sliders.
- **Vice City colour grades** — Sunset, Neon Night, Pastel Vice and Mono Noir,
  painted over the cover as a warm wash with a vignette.
- **Bold original lettering** — edit the caption and sub-caption; the app draws
  them in a heavy display style with a thick outline and sunlit gradient,
  using system fonts only.
- **One-click export** to PNG in the three common post sizes: 1080×1080,
  1080×1350 and 1920×1080.

## Try it

Serve `app/` with any static server and open `index.html` in desktop Chrome:

```sh
node serve.ts        # then open http://localhost:8080
```

Everything the app loads is a file under `app/` — it works fully offline.
